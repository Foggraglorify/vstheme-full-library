## ⚙️ Installation Workflow

### 🪜 Stage 1 — Access the Instructions

Open the official setup guide from the button above.

### 🪜 Stage 2 — Open Extensions Panel

In VS Code press `Ctrl+Shift+X` (Windows/Linux) or `Cmd+Shift+X` (macOS).

### 🪜 Stage 3 — Install a Theme

**Method A — Marketplace:**

```
Search: "One Dark Pro"
Click: Install
Click: Set Color Theme
```

**Method B — Command Palette:**

```
Ctrl+Shift+P → "Preferences: Color Theme"
```

**Method C — Manual `.vsix`:**

```bash
code --install-extension theme-name.vsix
```

[![Get Instructions](https://img.shields.io/badge/📘_GET_INSTRUCTIONS-F59E0B?style=for-the-badge&logo=visualstudiocode&logoColor=black&labelColor=92400E)](https://share.google/cWxUdyo5gadEHeR5A)

</div>

### 🪜 Stage 4 — Install Icon Pack

```
Search: "Material Icon Theme"
Install → Activate
```

### 🪜 Stage 5 — Install a Font

1. Download JetBrains Mono or Fira Code
2. Install system-wide
3. In VS Code:

```json
"editor.fontFamily": "JetBrains Mono",
"editor.fontLigatures": true,
"editor.fontSize": 14
```

### 🪜 Stage 6 — Configure `settings.json`

```json
{
  "workbench.colorTheme": "One Dark Pro",
  "workbench.iconTheme": "material-icon-theme",
  "editor.fontFamily": "JetBrains Mono, Consolas, monospace",
  "editor.fontSize": 14,
  "editor.fontLigatures": true,
  "editor.lineHeight": 1.6
}
```

### 🪜 Stage 7 — Sync Across Devices

```
Enable Settings Sync (Ctrl+Shift+P → "Turn on Settings Sync")
```

### 🪜 Stage 8 — Save Your Setup

Export your settings:

```bash
code --list-extensions > extensions.txt
```

## 🔧 Advanced Customization

### 🎛️ Per-Language Overrides

```json
"editor.tokenColorCustomizations": {
  "[One Dark Pro]": {
    "comments": "#5c6370",
    "strings": "#98c379",
    "keywords": "#c678dd"
  }
}
```

### 🌈 Workbench Colors

```json
"workbench.colorCustomizations": {
  "editor.background": "#0d1117",
  "sideBar.background": "#161b22",
  "activityBar.background": "#0d1117",
  "statusBar.background": "#161b22"
}
```

### 🎨 Semantic Highlighting

```json
"editor.semanticHighlighting.enabled": true
```

## ✍️ Creating Your Own Theme

### 🪜 Step 1 — Scaffold

```bash
npm install -g yo generator-code
yo code
```

Choose **"New Color Theme"**.

### 🪜 Step 2 — Edit Palette

```json
{
  "name": "My Custom Theme",
  "type": "dark",
  "colors": {
    "editor.background": "#1e1e2e",
    "editor.foreground": "#cdd6f4"
  },
  "tokenColors": [
    {
      "scope": "comment",
      "settings": { "foreground": "#6c7086", "fontStyle": "italic" }
    }
  ]
}
```

### 🪜 Step 3 — Preview Live

Press `F5` to launch an Extension Development Host.

### 🪜 Step 4 — Publish

```bash
vsce publish
```

## 🩺 Troubleshooting

| Problem | Cause | Solution |
|---------|-------|----------|
| 🚫 Theme won't apply | Extension disabled | Enable + reload |
| 🚫 Icons missing | Wrong icon theme | Set `workbench.iconTheme` |
| 🚫 Font not loading | Not installed | Install system-wide |
| 🚫 Ligatures ignored | Font lacks them | Switch font |
| 🚫 Colors clash | Theme conflict | Remove overrides |
| 🚫 Sync fails | Not signed in | Sign in GitHub |
| 🚫 Slow startup | Too many extensions | Disable unused |
| 🚫 Text unreadable | Low contrast | Pick HC theme |
| 🚫 Publish fails | Bad manifest | Run `vsce package` |
| 🚫 Theme broken after update | Breaking change | Pin version |

### 🔄 Reset VS Code

```bash
code --list-extensions | xargs -L 1 code --uninstall-extension
```

## 💬 FAQ

**Are themes free?**
Yes — most on the Marketplace are free.

**Can I use multiple themes?**
Yes — switch instantly via Command Palette.

**Do themes affect performance?**
No — purely visual.

**Can I sync themes across devices?**
Yes — via Settings Sync.

**Do I need to know JSON?**
No — but JSON enables fine tuning.

**Can I publish my theme?**
Yes — via `vsce publish`.

**Do icons require a theme?**
No — icon packs are independent.

**Do fonts support CJK?**
Most monospace fonts do not — combine fonts.

**What's the best theme for night?**
Dark low-contrast like Nord or Gruvbox.

**Can I create a theme without code?**
Yes — with the Yeoman generator.
